**IndieG** (`the-best-game-platform`) là nền tảng mạng xã hội và cộng đồng game thủ hiện đại, được xây dựng với mục tiêu kết nối những người đam mê trò chơi điện tử. Nơi đây cung cấp không gian toàn diện để game thủ thảo luận chiến thuật, tìm kiếm tổ đội leo rank (LFG - Looking For Group), khám phá kho game đồ sộ và tự hào phô diễn cá tính chơi game cùng dàn **Gaming Gear** cực chất.

---

## ✨ Tính Năng Nổi Bật

### 📰 1. Bảng Tin & Thảo Luận (Feed & Posts)
* **Đăng tải nội dung phong phú**: Tạo bài viết, chia sẻ kinh nghiệm, đánh giá tựa game yêu thích với định dạng chữ, đính kèm hình ảnh, GIF và biểu tượng cảm xúc (Emoji Picker).
* **Tương tác trực quan**: Hệ thống Thích (Like), Bình luận (Comment), Chia sẻ (Share) và Đánh dấu bài viết (Bookmark) để lưu trữ nội dung quan trọng.
* **Bộ lọc thông minh**: Dễ dàng chuyển đổi giữa các tab **Xu hướng (Trending)**, **Mới nhất (Latest)**, **Thảo luận (Discussions)**, **Hướng dẫn (Guides)** và **Tin tức (News)**.

### 🌐 2. Diễn Đàn Cộng Đồng (Communities)
* **Không gian chuyên sâu**: Các khu vực thảo luận được phân chia rõ ràng theo từng tựa game hoặc chủ đề (Esports, Indie Games, PC/Console, Mobile...).
* **Hoạt động sôi nổi**: Xem danh sách thành viên tích cực, bảng xếp hạng đóng góp và nội dung tiêu biểu của từng cộng đồng.

### ⚔️ 3. Tìm Tổ Đội & Ghép Đội Leo Rank (Squad & LFG)
* **Khám phá & Tạo Squad thần tốc**: Đăng tải hoặc tìm kiếm yêu cầu lập tổ đội chơi game theo danh mục tựa game (CS2, Valorant, LoL, PUBG, GTA V...).
* **Lọc theo tiêu chí chi tiết**:
  * **Mức Rank**: Từ Đồng, Bạc, Vàng, Bạch Kim, Kim Cương đến Cao Thủ / Thách Đấu.
  * **Vai trò (Role/Position)**: Tanker, Sniper, Support, Entry Fragger, IGL...
  * **Chế độ chơi**: Tryhard leo rank, Casual giải trí, Giao lưu học hỏi...
* **Kết nối tức thì**: Hỗ trợ chat, trò chuyện thoại và tham gia phòng chơi ngay lập tức.

### 🕹️ 4. Tủ Game & Thư Viện (Game Library)
* **Khám phá game đỉnh cao**: Tra cứu thông tin chi tiết, yêu cầu cấu hình (Minimum / Recommended specs) và đánh giá từ cộng đồng game thủ.
* **Quản lý tủ game cá nhân**: Thêm game vào danh sách yêu thích, theo dõi tiến độ và thông tin cập nhật mới nhất.

### 👤 5. Hồ Sơ Game Thủ Độc Quyền (Gamer Profile & Identity)
* **Tùy biến phong cách cá nhân**: Thay đổi ảnh đại diện (Avatar), ảnh bìa điện ảnh (Cover Banner), lựa chọn **Danh hiệu (Badges)** và Thẻ khung nhân vật.
* **🖥️ Gaming Gear Showcase**: Nơi game thủ tự hào trưng bày "vũ khí chiến đấu" thực tế của mình với các biểu tượng chuyên biệt:
  * CPU (Vi xử lý) & GPU (Card đồ họa)
  * Monitor (Màn hình gaming) & Mouse (Chuột gaming)
  * Keyboard (Bàn phím cơ) & Mousepad (Lót chuột)
  * Headphones (Tai nghe) & Audio / Soundcard / DAC
* **📊 Thống kê chiến tích**: Bảng tóm tắt chỉ số E-sports cá nhân (Số giờ chơi, tỷ lệ thắng, K/D ratio, danh hiệu MVP).
* **📖 Sổ Lưu Bút (Guestbook)**: Không gian tương tác thân thiện để bạn bè ghé thăm, để lại lời nhắn và kỷ niệm trên trang cá nhân.
* **🤝 Quản lý Bạn bè & Chặn người dùng**: Gửi lời mời kết bạn, chấp nhận/từ chối, hủy kết bạn và chặn người dùng vi phạm chỉ với vài thao tác nhanh chóng.

### 🔔 6. Thông Báo Thời Gian Thực (Real-time Notifications)
* Cập nhật tức thì khi có người thích bài viết, phản hồi bình luận, nhắc đến tên (@username) hoặc gửi lời mời kết bạn / mời vào Squad.

### 🌗 7. Giao Diện Hiện Đại & Đa Ngôn Ngữ (UI/UX & i18n)
* **Chế độ Sáng / Tối (Dark & Light Theme)**: Thiết kế chuẩn Glassmorphism & Neumorphic, tối ưu độ tương phản mắt nhìn cho game thủ cày đêm.
* **Đa ngôn ngữ**: Chuyển đổi mượt mà giữa **Tiếng Việt 🇻🇳** và **Tiếng Anh 🇬🇧** không cần tải lại trang.
* **Responsive 100%**: Trải nghiệm hoàn hảo trên Desktop, Tablet và Mobile.

### 🔐 8. Chế Độ Kiểm Thử Nhanh ([DEV] Mock Auth)
* Tích hợp sẵn hệ thống **Mock Login / Logout** ngay trên Header, cho phép người dùng và nhà phát triển trải nghiệm ngay lập tức toàn bộ các tính năng yêu cầu đăng nhập (Tạo bài viết, Sửa hồ sơ, Tạo Squad, Kết bạn...) mà không cần các bước đăng ký tài khoản phức tạp.

## 🛠️ Công Nghệ Sử Dụng

| Thành phần | Công nghệ / Thư viện |
| :--- | :--- |
| **Frontend Framework** | [React 19](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/) |
| **Build Tool & Bundler** | [Vite 8](https://vitejs.dev/) |
| **Routing System** | [TanStack Router v1](https://tanstack.com/router) (Type-safe file-based routing) |
| **State Management** | [Zustand v5](https://zustand-demo.pmnd.rs/) (Theme, Auth, Sidebar, Notifications, i18n) |
| **Styling & CSS** | [Tailwind CSS v4](https://tailwindcss.com/) (`@tailwindcss/vite`) |
| **Iconography** | [FontAwesome Icons v7](https://fontawesome.com/) (`@fortawesome/free-solid-svg-icons`, brands, regular) |
| **Backend / Auth** | [Supabase](https://supabase.com/) (`@supabase/supabase-js`) & Custom Local State Engine |
| **Tiện ích khác** | `emoji-picker-react` (Bộ chọn biểu tượng cảm xúc), `zxcvbn` (Kiểm tra độ mạnh mật khẩu) |

## 🚀 Hướng Dẫn Khởi Chạy Từ Thư Mục Frontend

### 1. Cài đặt Dependencies
```bash
npm install
```

### 2. Khởi chạy Development Server
```bash
npm run dev
```
👉 Ứng dụng sẽ chạy tại cổng **3000**: **`http://localhost:3000`**

### 3. Build & Preview
```bash
npm run build
npm run preview
```
